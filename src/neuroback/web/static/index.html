Phase sweep

Four target phases and two controls with the same flash rate (open-loop flicker at the IAF, random phase), repeated in randomised blocks. Alpha is measured in the stimulus-free gap after each block, where there is no steady-state visual response.

Stimulate

The endpoint-corrected Hilbert transform estimates the alpha phase at every sample and one flash is scheduled per cycle at the target phase. Dots on the dial show where recent flashes landed, measured afterwards with a non-causal Hilbert transform.
